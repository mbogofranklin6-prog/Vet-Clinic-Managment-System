# Vet-Clinic-Managment-System
# 🐾 PawCare Veterinary Clinic Management System

## 📖 Project Description

PawCare Veterinary Clinic Management System is a web-based application developed using HTML, CSS, and JavaScript. It helps veterinary clinics manage pet records, appointments, treatments, and vaccination records in one place. The application uses Local Storage to save data, allowing users to manage clinic information without a database.

---

## ✨ Features

- 🏠 Home Page
- ℹ️ About Page
- 🩺 Services Page
- 🐶 Pet Registration
- 📅 Appointment Booking
- 📊 Dashboard
- 💊 Treatment Records
- 💉 Vaccination Records
- 📞 Contact Page
- 🔍 Search Pets
- 🗑️ Delete Pet Records
- 💾 Local Storage for Data Persistence
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Font Awesome
- Google Fonts (Poppins)
